# Forum Bot — Majestic RP

Бот мониторинга форума с автоответами и уведомлениями в Telegram.

## Быстрый старт

### 1. Получить ID канала
Добавь бота в канал как администратора, затем перешли любое сообщение из канала боту @userinfobot — он покажет ID канала (начинается с -100...).

### 2. Заполнить .env
Скопируй `.env.example` → `.env` и заполни:
```
BOT_TOKEN=твой_токен
ADMIN_ID=6215847916
CHANNEL_ID=-100xxxxxxxxxx  ← ID канала
```

### 3. Локальный запуск (для теста)
```bash
pip install -r requirements.txt
python bot.py
```

### 4. Деплой на Railway (бесплатно, 24/7)

1. Зарегистрируйся на https://railway.app (через GitHub)
2. Нажми **New Project → Deploy from GitHub repo**
3. Загрузи код в свой GitHub репозиторий
4. В Railway: **Variables** → добавь переменные из .env
5. Нажми **Deploy** — бот запустится автоматически

> ⚠️ Файл `.env` НЕ загружай на GitHub! Переменные вводи только через Railway Variables.

## Команды бота

| Команда | Действие |
|---------|----------|
| /start | Главное меню |
| /cancel | Отмена текущего действия |

Всё управление через кнопки в боте.

---

## Как пользоваться

1. Запусти бота → /start
2. Нажми **Авторизация форума** → введи логин/пароль
3. Если потребуется — введи код из Google Authenticator
4. В настройках задай **шаблон ответа**
5. Нажми **Старт** — бот начнёт мониторинг

---

## Логика проверки жалоб

Бот проверяет каждую новую тему на:
- ✅ Все 6 полей заполнены
- ✅ Доказательства на разрешённых платформах (YouTube, Imgur, Google Drive и т.д.)
- ✅ Для DM/DB/PG/NonRP — наличие видео
- ✅ Тема не занята другим администратором

При нарушении — указывает конкретный пункт правил в ответе.
